# Library Documentation Policy

This directory contains up-to-date documentation for libraries used in the project. 

- Each library has its own markdown file (e.g., `zod.md`, `colyseus.md`).
- If you find missing information or outdated sections, update the file using information from official documentation.
- When working on a feature, consult these docs first.
- Keep them concise: summaries of functions and concepts.
